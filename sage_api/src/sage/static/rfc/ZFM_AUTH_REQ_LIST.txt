ZFM_AUTH_REQ_LIST - custom RFC that lists the authorization objects and values a function module needs
=======================================================================================================

Owned by sap_system_management and used by its
tool_sapSYS_authRequirements (/sys auth_requirements). Meant for documenting what
a user needs before a custom FM can run completely.

WHY THIS EXISTS
---------------
The documentation for each custom RFC FM must state which authorization objects
(and field values) the calling user needs. Reading that by hand from the source is
slow and error-prone, especially when the FM only delegates to a class.

WHAT IT DOES
------------
Static mode (IV_MODE = 'S'):
  1. Always returns the S_RFC rows for the RFC call itself (RFC_TYPE = FUNC,
     RFC_NAME = the FM or its function group, ACTVT = 16).
  2. Reads the FM's function include (TFDIR -> L<group>U<nn>) and scans it with
     SCAN ABAP-SOURCE.
  3. Extracts every AUTHORITY-CHECK: object, each ID, and its FIELD value. A literal
     value is returned as-is. A name that matches a CONSTANTS ... VALUE 'x' in the
     scanned source (and has only one such value) is replaced by that value. Any
     other name is returned as <NAME> because the real value is only known at run
     time. DUMMY is returned as "(DUMMY - not checked)".
  4. Follows, down to IV_MAX_DEPTH levels:
       - INCLUDE statements
       - CALL FUNCTION 'LITERAL' (custom Z*/Y* only, unless IV_INCL_STANDARD = 'X')
       - PERFORM <form> (forms are looked up in the includes of the same function group)
       - any custom global class named Z*CL_* / Y*CL_* in a statement, and any local class
         LCL_* defined in an include of the same function group (e.g. the classes in
         LZFG_MCPARCHPHRRC and LZFG_MCPARCHPHRCC). The WHOLE class is scanned, not only the method actually
         called - a deliberate over-approximation, so a method the FM never reaches can
         add a row.
  5. Everything it cannot follow is returned in "unresolved" with a reason: dynamic
     CALL FUNCTION name, CALL FUNCTION ... DESTINATION, PERFORM (name) or PERFORM ... IN
     PROGRAM, SAP-standard callees not followed, source not readable, depth limit reached.
     THE LIST IS NEVER SILENTLY SHORTER THAN WHAT THE FM REALLY CHECKS - read "unresolved".

Trace mode (IV_MODE = 'T' or 'B'): NOT IMPLEMENTED. The FM returns a warning message in
ET_RETURN and the static result for 'B'. See STEP 5.

Derived without running it: nothing in this spec has been activated on a system yet.
Expect to fix small syntax/typing issues on first activation (see STEP 4).


JSON RETURNED IN EV_JSON
------------------------
{
  "rows": [
    {"auth_object": "S_BTCH_JOB", "auth_field": "JOBACTION", "auth_values": "RELE",
     "source": "STATIC:LZFG_MCPARCHPHRCC:140", "depth": 1,
     "callee_path": "ZFM_RC_NOTES_DOWNLOAD>CLASS LCL_RC_NOTES_DOWNLOAD"}
  ],
  "unresolved": ["CALL FUNCTION <LV_FM> (dynamic name, line in LZFG_MCPARCHPHU01)"]
}
source is "RFC_CALL" for the S_RFC rows and "STATIC:<include>:<line>" for the rest.


SETUP (SE80/SE37, local object $TMP)
------------------------------------
STEP 1. Function group: reuse ZFG_MCPARCHPH (create it if no other capability's RFC
        setup has yet). Never a per-capability group.

STEP 2. Create the include LZFG_MCPARCHPHSYC for the local class LCL_AUTH_REQ_LIST (code
        below) and add its INCLUDE statement to the function group's main program, next to
        the other class includes (LZFG_MCPARCHPHRRC, LZFG_MCPARCHPHRCC). It does not depend on
        the classes in them. A local class is visible to every function module of
        ZFG_MCPARCHPH. Activate the include.

STEP 3. Create function module ZFM_AUTH_REQ_LIST in ZFG_MCPARCHPH, processing type
        "Remote-Enabled Module" (Attributes tab). Define the interface (all PASS BY
        VALUE) and paste only the body:

  Importing  IV_FUNCNAME       TYPE RS38L_FNAM
  Importing  IV_MODE           TYPE CHAR1          default 'S'
  Importing  IV_MAX_DEPTH      TYPE I              default 3
  Importing  IV_INCL_STANDARD  TYPE CHAR1          optional
  Importing  IV_TRACE_USER     TYPE SYUNAME        optional
  Exporting  EV_JSON           TYPE STRING
  Exporting  ET_RETURN         TYPE BAPIRET2_T

  Body:

  DATA(result) = NEW lcl_auth_req_list( )->analyze(
    funcname      = iv_funcname
    mode          = iv_mode
    max_depth     = iv_max_depth
    incl_standard = iv_incl_standard
    trace_user    = iv_trace_user ).

  ev_json   = result-json.
  et_return = result-return.

STEP 4. Things to check on first activation (not confirmed on a system):
  a. READ REPORT needs a character-like program name and a flat character table (not
     STRING): the code uses PROGNAME and ABAPTXT255_TAB for this. The program name
     part was confirmed by TS3's syntax check ("INCLUDE_NAME must be a character-like
     field"); the table type is not yet confirmed.
     SCAN needs WITH ANALYSIS because the token table is STOKESX (STRING tokens, so
     long literals are not cut at 30 characters like STOKES would); confirmed by TS3's
     syntax check ("offset and length fields ... not filled until WITH ANALYSIS").
  b. /UI2/CL_JSON must exist (SAP_UI component). If it does not, replace the serialize
     call with a hand-built JSON string.
  c. The class pool program is named <class name padded with '=' to 30 characters>CP
     (built in the code, no CL_OO_CLASSNAME_SERVICE call: GET_CP_NAME does not exist). It
     includes the method includes (CM001...) - confirm with one known class.
  d. Function include name: the code builds L<group>U<nn> from TFDIR-PNAME and
     TFDIR-INCLUDE. Confirm with one FM whose include you know (SE37 > Goto >
     Main program).
  e. D010INC (MASTER/INCLUDE) is used to find the includes holding FORM routines and
     local classes. If it is empty for the group, generate the program once
     (SE80 > Activate) and retry.
  f. Test on ZFM_CHECK_JOB_STATUS (calls only BP_JOB_STATUS_GET, no AUTHORITY-CHECK of its
     own): expect the three S_RFC rows, the S_DEVELOP check of this FM itself is NOT part
     of the result. Then test on ZFM_RC_NOTES_DOWNLOAD: expect S_BTCH_JOB with
     JOBACTION = RELE and JOBGROUP = *.
     Then test on ZFM_RR_DERIVED_REGENERATE: expect S_USER_AGR with ACT_GROUP = <ROLE>
     (a variable) and ACTVT = 02 (constant resolved), found at depth 1 through
     LCL_RR_DERIVED_REGEN. The PRGN_* function modules it calls are SAP standard, so
     they show in "unresolved"; use IV_INCL_STANDARD = 'X' to look inside them.

STEP 5. Trace mode (open): the authorization trace (ST01 / STAUTHTRACE) is not read
  yet because where it is stored differs by release and has not been identified on
  the target system. When it is, implement READ_TRACE in the class below and add the
  rows with source = "TRACE". Until then mode T returns a warning and mode B returns
  the static result with the same warning.

AUTHORIZATIONS THIS FM NEEDS ITSELF
-----------------------------------
  - Calling user:  S_RFC  (RFC_TYPE FUNC, RFC_NAME ZFG_MCPARCHPH, ACTVT 16)
  - Inside the FM: S_DEVELOP (ACTVT 03, OBJTYPE FUGR, other fields dummy). It is
    checked before any source is read, so the RFC user cannot be used to read code it
    could not display in SE80.

CLASS lcl_auth_req_list DEFINITION
  FINAL.

  PUBLIC SECTION.
    TYPES: BEGIN OF row,
             auth_object TYPE string,
             auth_field  TYPE string,
             auth_values TYPE string,
             source      TYPE string,
             depth       TYPE i,

    METHODS analyze

                max_depth     TYPE i
                incl_standard TYPE char1
                trace_user    TYPE syuname

CLASS lcl_auth_req_list IMPLEMENTATION.

  METHOD analyze.
    IF mode NA 'STB' OR max_depth < 0 OR max_depth > 10.
      result-return = VALUE #( ( type = 'E' message = 'IV_MODE must be S, T or B and IV_MAX_DEPTH 0..10' ) ).
      RETURN.
    ENDIF.
    IF is_allowed( ) = abap_false.
      result-return = VALUE #( ( type = 'E' message = 'No authorization to read function group source (S_DEVELOP display)' ) ).
      RETURN.
    ENDIF.

    DATA(fm) = CONV rs38l_fnam( to_upper( funcname ) ).
    SELECT SINGLE funcname FROM tfdir WHERE funcname = @fm INTO @DATA(found).
    IF sy-subrc <> 0.
      result-return = VALUE #( ( type = 'E' message = |Function module { fm } not found| ) ).
      RETURN.
    ENDIF.

    depth_limit     = max_depth.
    follow_standard = xsdbool( incl_standard = 'X' ).

    IF mode CA 'SB'.
      add_rfc_rows( fm ).
      scan_function( funcname = fm ctx = VALUE #( path = fm ) ).
    ENDIF.
    IF mode CA 'TB'.
      INSERT VALUE #( type = 'W'
                      message = |Trace mode is not implemented (trace user { trace_user }); static result only| )
        INTO TABLE result-return.
    ENDIF.

    resolve_constants( ).
    DATA(out) = VALUE output( rows = found_rows unresolved = unresolved ).
    result-json = /ui2/cl_json=>serialize(
      data        = out
      pretty_name = /ui2/cl_json=>pretty_mode-low_case ).
  ENDMETHOD.


  METHOD is_allowed.
    AUTHORITY-CHECK OBJECT 'S_DEVELOP'
      ID 'DEVCLASS' DUMMY
      ID 'OBJTYPE'  FIELD 'FUGR'
      ID 'OBJNAME'  DUMMY
      ID 'P_GROUP'  DUMMY
      ID 'ACTVT'    FIELD '03'.
    result = xsdbool( sy-subrc = 0 ).
  ENDMETHOD.


  METHOD add_rfc_rows.
    SELECT SINGLE pname FROM tfdir WHERE funcname = @funcname INTO @DATA(pname).
    DATA(group) = CONV string( pname ).
    REPLACE FIRST OCCURRENCE OF 'SAPL' IN group WITH ''.
    DATA(ctx) = VALUE context( path = funcname ).
    add_row( auth_object = 'S_RFC' auth_field = 'RFC_TYPE' auth_values = 'FUNC' source = 'RFC_CALL' ctx = ctx ).
    add_row( auth_object = 'S_RFC' auth_field = 'RFC_NAME'
             auth_values = |{ funcname } or function group { group }| source = 'RFC_CALL' ctx = ctx ).
    add_row( auth_object = 'S_RFC' auth_field = 'ACTVT' auth_values = '16' source = 'RFC_CALL' ctx = ctx ).
  ENDMETHOD.


  METHOD scan_function.
    IF ctx-depth > depth_limit.
      note( |{ funcname } (depth limit { depth_limit } reached)| ).
      RETURN.
    ENDIF.
    IF line_exists( seen[ table_line = |FM:{ funcname }| ] ).
      RETURN.
    ENDIF.
    APPEND |FM:{ funcname }| TO seen.

    SELECT SINGLE pname, include FROM tfdir WHERE funcname = @funcname INTO @DATA(tf).
    IF sy-subrc <> 0.
      note( |{ funcname } (function module not found)| ).
      RETURN.
    ENDIF.

    DATA(program) = CONV string( tf-pname ).
    DATA(function_include) = program.
    REPLACE FIRST OCCURRENCE OF 'SAPL' IN function_include WITH 'L'.
    function_include = |{ function_include }U{ tf-include }|.

    scan_include( include_name = function_include
                  ctx     = VALUE #( include = function_include
                                     group   = program
                                     depth   = ctx-depth
                                     path    = ctx-path ) ).
  ENDMETHOD.


  METHOD scan_include.
    DATA(name) = to_upper( include_name ).
    IF line_exists( seen[ table_line = |INC:{ name }| ] ).
      RETURN.
    ENDIF.
    APPEND |INC:{ name }| TO seen.

    load( EXPORTING include_name = name
          IMPORTING tokens     = DATA(tokens)
                    statements = DATA(statements)
                    ok         = DATA(ok) ).
    IF ok = abap_false.
      note( |{ name } (source not readable)| ).
      RETURN.
    ENDIF.

    DATA(here) = ctx.
    here-include = name.
    LOOP AT statements INTO DATA(statement).
      handle_statement( tokens = tokens statement = statement ctx = here ).
    ENDLOOP.
  ENDMETHOD.


  METHOD load.
    DATA source TYPE abaptxt255_tab.
    DATA program TYPE progname.

    program = include_name.
    READ REPORT program INTO source.
    IF sy-subrc <> 0.
      ok = abap_false.
      RETURN.
    ENDIF.
    SCAN ABAP-SOURCE source TOKENS INTO tokens STATEMENTS INTO statements WITH ANALYSIS.
    ok = xsdbool( tokens IS NOT INITIAL ).
    IF ok = abap_true.
      collect_constants( tokens = tokens statements = statements ).
    ENDIF.
  ENDMETHOD.


  METHOD handle_statement.
    IF statement-from > statement-to.
      RETURN.
    ENDIF.

    DATA words TYPE strings.
    LOOP AT tokens INTO DATA(token) FROM statement-from TO statement-to.
      APPEND token-str TO words.
    ENDLOOP.

    DATA(line) = tokens[ statement-from ]-row.
    CASE to_upper( words[ 1 ] ).
      WHEN 'AUTHORITY-CHECK'.
        add_authority_check( words = words line = line ctx = ctx ).
      WHEN 'INCLUDE'.
        IF lines( words ) = 2 OR ( lines( words ) = 4 AND to_upper( words[ 3 ] ) = 'IF' ).
          scan_include( include_name = words[ 2 ] ctx = ctx ).
        ENDIF.
      WHEN 'CALL'.
        IF lines( words ) >= 3 AND to_upper( words[ 2 ] ) = 'FUNCTION'.
          follow_call_function( words = words ctx = ctx ).
        ENDIF.
      WHEN 'PERFORM'.
        follow_perform( words = words ctx = ctx ).
    ENDCASE.

    follow_class_refs( words = words ctx = ctx ).
  ENDMETHOD.


  METHOD add_authority_check.
    IF lines( words ) < 3 OR to_upper( words[ 2 ] ) <> 'OBJECT'.
      note( |AUTHORITY-CHECK without literal OBJECT clause ({ ctx-include }:{ line })| ).
      RETURN.
    ENDIF.

    DATA(object) = value_of( words[ 3 ] ).
    DATA(source) = |STATIC:{ ctx-include }:{ line }|.
    DATA(i) = 4.
    WHILE i <= lines( words ).
      IF to_upper( words[ i ] ) = 'ID' AND i + 2 <= lines( words ).
        DATA(id_field) = value_of( words[ i + 1 ] ).
        DATA(kind) = to_upper( words[ i + 2 ] ).
        IF kind = 'FIELD' AND i + 3 <= lines( words ).
          add_row( auth_object = object auth_field = id_field
                   auth_values = value_of( words[ i + 3 ] ) source = source ctx = ctx ).
          i = i + 4.
        ELSEIF kind = 'DUMMY'.
          add_row( auth_object = object auth_field = id_field
                   auth_values = '(DUMMY - not checked)' source = source ctx = ctx ).
          i = i + 3.
        ELSE.
          i = i + 1.
        ENDIF.
      ELSE.
        i = i + 1.
      ENDIF.
    ENDWHILE.
  ENDMETHOD.


  METHOD follow_call_function.
    IF is_literal( words[ 3 ] ) = abap_false.
      note( |CALL FUNCTION { words[ 3 ] } (dynamic name, in { ctx-include })| ).
      RETURN.
    ENDIF.

    DATA(callee) = CONV rs38l_fnam( to_upper( value_of( words[ 3 ] ) ) ).
    LOOP AT words TRANSPORTING NO FIELDS WHERE table_line CP 'DESTINATION'.
      note( |{ callee } (remote call via DESTINATION, in { ctx-include })| ).
      RETURN.
    ENDLOOP.

    IF callee(1) NA 'ZY' AND follow_standard = abap_false.
      note( |{ callee } (SAP standard, not followed)| ).
      RETURN.
    ENDIF.

    scan_function( funcname = callee
                   ctx      = VALUE #( BASE ctx depth = ctx-depth + 1 path = |{ ctx-path }>{ callee }| ) ).
  ENDMETHOD.


  METHOD follow_perform.
    IF lines( words ) < 2.
      RETURN.
    ENDIF.
    IF words[ 2 ] CS '('.
      note( |PERFORM { words[ 2 ] } (dynamic name, in { ctx-include })| ).
      RETURN.
    ENDIF.
    LOOP AT words TRANSPORTING NO FIELDS WHERE table_line CP 'PROGRAM'.
      note( |PERFORM { words[ 2 ] } (IN PROGRAM, not followed, in { ctx-include })| ).
      RETURN.
    ENDLOOP.
    follow_form( form = to_upper( words[ 2 ] ) ctx = ctx ).
  ENDMETHOD.


  METHOD follow_form.
    follow_block( kind = 'FORM' name = form end_kind = 'ENDFORM' ctx = ctx ).
  ENDMETHOD.


  METHOD follow_block.
    " Scans one FORM ... ENDFORM or CLASS ... IMPLEMENTATION ... ENDCLASS block that
    " lives in an include of the caller's function group.
    DATA(label) = |{ kind } { name }|.
    IF ctx-group IS INITIAL.
      note( |{ label } (location unknown, in { ctx-include })| ).
      RETURN.
    ENDIF.
    IF ctx-depth + 1 > depth_limit.
      note( |{ label } (depth limit { depth_limit } reached)| ).
      RETURN.
    ENDIF.
    IF line_exists( seen[ table_line = |BLK:{ ctx-group }:{ label }| ] ).
      RETURN.
    ENDIF.
    APPEND |BLK:{ ctx-group }:{ label }| TO seen.

    SELECT include FROM d010inc WHERE master = @ctx-group INTO TABLE @DATA(includes).
    LOOP AT includes INTO DATA(inc).
      load( EXPORTING include_name = CONV string( inc-include )
            IMPORTING tokens       = DATA(tokens)
                      statements   = DATA(statements)
                      ok           = DATA(ok) ).
      IF ok = abap_false.
        CONTINUE.
      ENDIF.

      DATA(inside) = abap_false.
      LOOP AT statements INTO DATA(statement).
        IF statement-from > statement-to.
          CONTINUE.
        ENDIF.
        DATA(first) = to_upper( tokens[ statement-from ]-str ).
        IF inside = abap_false.
          IF first = kind AND statement-to > statement-from
             AND to_upper( tokens[ statement-from + 1 ]-str ) = name
             AND ( kind <> 'CLASS'
                   OR ( statement-to > statement-from + 1
                        AND to_upper( tokens[ statement-from + 2 ]-str ) = 'IMPLEMENTATION' ) ).
            inside = abap_true.
          ENDIF.
          CONTINUE.
        ENDIF.
        IF first = end_kind.
          RETURN.
        ENDIF.
        handle_statement(
          tokens    = tokens
          statement = statement
          ctx       = VALUE #( include = CONV string( inc-include )
                               group   = ctx-group
                               depth   = ctx-depth + 1
                               path    = |{ ctx-path }>{ label }| ) ).
      ENDLOOP.
      IF inside = abap_true.
        RETURN.
      ENDIF.
    ENDLOOP.
    note( |{ label } (not found in the includes of { ctx-group })| ).
  ENDMETHOD.


  METHOD follow_class_refs.
    DATA(text) = to_upper( concat_lines_of( table = words sep = ` ` ) ).
    FIND ALL OCCURRENCES OF PCRE '\b(?:[ZY]CL_|LCL_)[A-Z0-9_]+' IN text RESULTS DATA(matches).
    LOOP AT matches INTO DATA(match).
      follow_class( class_name = substring( val = text off = match-offset len = match-length ) ctx = ctx ).
    ENDLOOP.
  ENDMETHOD.


  METHOD follow_class.
    IF substring( val = class_name len = 1 ) = 'L'.
      " local class: defined in an include of the caller's function group
      follow_block( kind = 'CLASS' name = class_name end_kind = 'ENDCLASS' ctx = ctx ).
      RETURN.
    ENDIF.
    IF line_exists( seen[ table_line = |CL:{ class_name }| ] ).
      RETURN.
    ENDIF.
    SELECT SINGLE clsname FROM seoclass WHERE clsname = @class_name INTO @DATA(exists).
    IF sy-subrc <> 0.
      RETURN.
    ENDIF.
    IF ctx-depth + 1 > depth_limit.
      note( |{ class_name } (depth limit { depth_limit } reached)| ).
      RETURN.
    ENDIF.
    APPEND |CL:{ class_name }| TO seen.

    " Class pool program name: class name padded with '=' to 30 characters, then CP
    DATA(pool) = |{ class_name WIDTH = 30 PAD = '=' }CP|.
    scan_include( include_name = pool
                  ctx          = VALUE #( include = pool
                                          group   = ``
                                          depth   = ctx-depth + 1
                                          path    = |{ ctx-path }>{ class_name }| ) ).
  ENDMETHOD.


  METHOD collect_constants.
    " CONSTANTS name ... VALUE 'literal' -> remembered so AUTHORITY-CHECK FIELD name can show its value
    LOOP AT statements INTO DATA(statement).
      IF statement-from >= statement-to
         OR to_upper( tokens[ statement-from ]-str ) <> 'CONSTANTS'.
        CONTINUE.
      ENDIF.
      DATA(const_name) = to_upper( tokens[ statement-from + 1 ]-str ).
      IF const_name = 'BEGIN' OR const_name = 'END'.
        CONTINUE.
      ENDIF.
      LOOP AT tokens INTO DATA(token) FROM statement-from + 2 TO statement-to.
        IF to_upper( token-str ) = 'VALUE'.
          DATA(value_index) = sy-tabix + 1.
          IF value_index <= statement-to AND is_literal( tokens[ value_index ]-str ) = abap_true.
            DATA(entry) = VALUE constant_entry( const_name  = const_name
                                                const_value = value_of( tokens[ value_index ]-str ) ).
            IF NOT line_exists( known_constants[ const_name = entry-const_name const_value = entry-const_value ] ).
              APPEND entry TO known_constants.
            ENDIF.
          ENDIF.
          EXIT.
        ENDIF.
      ENDLOOP.
    ENDLOOP.
  ENDMETHOD.


  METHOD resolve_constants.
    LOOP AT found_rows REFERENCE INTO DATA(row).
      row->auth_object = resolve( row->auth_object ).
      row->auth_field  = resolve( row->auth_field ).
      row->auth_values = resolve( row->auth_values ).
    ENDLOOP.
  ENDMETHOD.


  METHOD resolve.
    " <NAME> -> value, only when every CONSTANTS definition of NAME agrees on one value
    result = text.
    IF strlen( text ) < 3
       OR substring( val = text len = 1 ) <> '<'
       OR substring( val = text off = strlen( text ) - 1 len = 1 ) <> '>'.
      RETURN.
    ENDIF.
    DATA(wanted) = substring( val = text off = 1 len = strlen( text ) - 2 ).
    DATA found_values TYPE strings.
    LOOP AT known_constants INTO DATA(entry) WHERE const_name = wanted.
      IF NOT line_exists( found_values[ table_line = entry-const_value ] ).
        APPEND entry-const_value TO found_values.
      ENDIF.
    ENDLOOP.
    IF lines( found_values ) = 1.
      result = found_values[ 1 ].
    ENDIF.
  ENDMETHOD.


  METHOD add_row.
    APPEND VALUE #( auth_object = auth_object
                    auth_field  = auth_field
                    auth_values = auth_values
                    source      = source
                    depth       = ctx-depth
                    callee_path = ctx-path ) TO found_rows.
  ENDMETHOD.


  METHOD note.
    IF NOT line_exists( unresolved[ table_line = text ] ).
      APPEND text TO unresolved.
    ENDIF.
  ENDMETHOD.


  METHOD is_literal.
    result = xsdbool( strlen( word ) >= 2 AND ( word(1) = `'` OR word(1) = '`' ) ).
  ENDMETHOD.


  METHOD value_of.
    IF is_literal( word ) = abap_true.
